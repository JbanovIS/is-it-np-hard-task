# Выявить источники из статьи Seurin, потенциально содержащие доказательство NP-сложности

Запрос пользователя: «Выясни, в каких источниках (в какой литературе) из той, что использовалась в статье, может содержаться доказательство об NP-сложности задачи? ... Выяви все источники, которые потенциально могут содержать доказательство NP-сложности задачи. Создай соответствующий ".csv" файл в папке "results". Назови этот файл "literature about NP_hard from __Assessment of__".»

Готово, когда: создан `results/literature about NP_hard from __Assessment of__.csv` с колонками «название статьи», «обоснование», «оценка вероятности (низкая/большая)»; пользователь подтвердил корректность выполнения.
Не входит: поиск и полное изучение самих статей в интернете.

## План
1. Выявить источники из `manuscripts.bib`, цитируемые в контексте NP-сложности/CO-задач в `Manuscripts.tex`.
2. Оценить каждый источник по названию, общим знаниям и контексту цитирования.
3. Создать CSV-файл в `results/`.
4. Запросить подтверждение пользователя.

## Итог
Создан `results/literature about NP_hard from __Assessment of__.csv` (utf-8-sig) с 16 источниками из `manuscripts.bib`, цитируемыми в контексте NP-сложности/CO-задач (строки 183, 299, 311, 324, 342, 376 `Manuscripts.tex`). Колонки: название статьи, обоснование, оценка вероятности. Единственный источник с «большой вероятностью» — обзор Mazyavkina et al. 2021 (RL for CO), цитируемый прямо в строке 299 в контексте утверждения об NP-сложности. Остальные 15 — «низкая вероятность».
