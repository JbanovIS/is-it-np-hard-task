# Заметки сессии

## Задача
Проверить, содержит ли статья «Assessment of reinforcement learning algorithms for nuclear power plant fuel optimization» (Paul Seurin) доказательство NP-сложности задачи оптимизации схемы загрузки ядерного топлива.

## Результат
**Нет.** Статья не содержит ни математического доказательства NP-сложности задачи загрузки, ни прямой ссылки на статью с таким доказательством.

## Ключевые факты
- Единственное упоминание NP-сложности — строка 299 `Manuscripts.tex`: «CO problems are by essence extraordinarily hard to solve, in that they are NP-hard problems». Это общее утверждение о классе CO, задача загрузки отнесена к CO имплицитно.
- Пример в статье — TSP с алгоритмом Хелда–Карпа O(n²·2ⁿ), не задача загрузки.
- Единственная ссылка в утверждении — `bertsimas2008introduction` (учебник по линейной оптимизации), используется для TSP, не для NP-сложности задачи загрузки.
- Прочие упоминания «трудности» (строки 124–125, 174, 342, 376) — про класс CO, размер пространства поиска (~10⁵²→10²⁹) и трудность обеспечения допустимости; это не NP-сложность и не ссылки на доказательство.
