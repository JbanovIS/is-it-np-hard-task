# AGENTS.md — шаблон

Скопируйте файл в корень своего проекта под именем `AGENTS.md`. На этой
неделе полностью заполняются разделы 0, 1, 4, 5 (режим работы) и 7; в
разделах 2, 3, 6 — по одной-две строки, подробно они пишутся на неделе 3.
Образцы для пяти видов работы — в папке `agents_examples/`.

Файл читается агентом в начале каждой сессии. Правило отбора строк: если
строку убрать, ошибётся ли агент? Если нет — строка лишняя.

Другие агенты читают этот файл под именами `AGENTS.md`, `CLAUDE.md`,
`.cursorrules`, `.goosehints`.

## 0. Цель и образ результата

> Изучи документы "annexe.tex", "manuscripts.bib" и "Manuscripts.tex" из папки "paper/Assessment of RL". Эти документы являются статьёй "Assessment of reinforcement learning algorithms for nuclear power plant fuel optimization" by Paul Seurin. В этих документах данная статья представлена полностью в формате ".tex". В папке отсутствуют картинки (хотя в самой статье они есть), но они не нужны тебе для решения задаваемой мной задачи. Выясни, есть ли в данной статье доказательство того, что решаемая в работе задача оптимизации схемы загрузки ядерного топлива является NP-hard задачей? За доказательство NP-сложности задачи будем считать математическое доказательство или прямую ссылку на статью(и), где это доказательство есть. 

В конце в проекте в папке `results` существуют:
- `review.md` — вывод о наличии/отстутствии доказательства NP-сложности задачи с обоснованием;
- `claims.csv` — проверенные утверждения об NP-сложности задачи из статьи "Assessment of RL...", которые представлены в соответствии с шаблоном `review_template.csv`.

Ничего больше создавать не надо.

## 4. Запреты

У каждого запрета — пометка, где он обеспечивается. Пометка — запись для
вас: агент прочитает её вместе с запретом, но сама она ничего не
обеспечивает. Проверка: если удалить строку из этого файла,
действует ли запрет? Нет — `[окно]`; да — `[вызов]` или `[среда]`.

- `[окно]` — только текст в окне контекста модели; действует на слово;
- `[вызов]` — ведущее приложение проверяет вызов до исполнения: инструмента
  нет в списке, аргумент не проходит проверку, действие требует подтверждения;
- `[среда]` — механизм среды: права доступа, отдельная копия, инвариант с откатом.

- запрещено изменять документы из папки`paper/`. `[среда]` — `chmod -R a-w paper`.
- не изменять файлы в `checks/`. `[среда]` — `chmod -R a-w checks`
- не читать содержимое `checks/check.py` (только запускать). `[окно]` 
- запрещено читать и выводить содержимое `.env` и других файлов с ключами `[среда + вызов]`.
- запрещено выполнять `git push`, `rm -rf`, `sudo` без подтверждения `[вызов]`.
